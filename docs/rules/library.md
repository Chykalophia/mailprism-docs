# Rule Library

You don't have to start with a blank rule. The **Rule Library** is a gallery of
ready-made templates for common email chores. Pick one, customize it to your inbox,
and enable it.

Open it from **Rules → Browse Templates**.

## Browse by category

Templates are organized into categories so you can find the right starting point fast.
Use the **search box** to filter by name or description, or the **category buttons**
to narrow the list. Each card also shows how many **conditions** and **actions** the
rule contains, plus badges:

| Badge | Meaning |
|-------|---------|
| <span class="mp-pill mp-pill--blue">AI</span> | The template uses AI conditions |
| <span class="mp-pill mp-pill--green">New</span> | Recently added |
| <span class="mp-pill mp-pill--amber">Beta</span> | Still being refined |
| <span class="mp-pill mp-pill--violet">Popular</span> | A common favorite |
| <span class="mp-pill mp-pill--violet">Pro</span> / <span class="mp-pill mp-pill--blue">Enterprise</span> | Needs that plan — see [Tier-gated templates](#tier-gated-templates) |

| Category | What it covers |
|----------|----------------|
| **Newsletters** | Manage subscriptions and mailing lists |
| **Receipts & Purchases** | Organize orders and deliveries |
| **Spam & Cold Emails** | Block unwanted messages |
| **Priority Management** | Flag important and urgent emails |
| **AI-Powered** | Smart automation that uses AI |
| **Professional** | Business and work email |
| **FYI & Informational** | Non-actionable updates and information |
| **Personal & Notes** | Self-sent emails and reminders |
| **Notifications** | Automated system messages |
| **Automation** | Processed and AI-handled email |
| **Response Tracking** | Track emails that need responses |

## Installing a template

1. Go to **Rules → Browse Templates**.
2. Browse or search for a template that fits what you want.
3. Click **Use Template**.

That creates a new rule from the template's conditions and actions.

:::caution New rules start turned off
An installed template is created **disabled by default**. Review it, adjust the
conditions and actions to your inbox (for example, change a label name or a sender
keyword), then **enable** it when you're ready. Customizing an installed template
never affects the original — you can always come back for a fresh copy.
:::

Once installed, the card shows **Edit Rule**, which opens the rule so you can fine-tune
it like any rule you built yourself.

## Restoring a removed template

If you remove an installed template (the **trash** button on its card), the template
isn't gone — it returns to the gallery as available again. To bring it back, simply
**use the template again** to install a fresh copy.

:::tip Keep the original
Because templates and your installed rules are separate, removing an installed rule
leaves the template intact. Reinstalling always starts from the clean, ready-made
version.
:::

## Tier-gated templates

Some templates are available on higher plans and show a small badge:

- A <span class="mp-pill mp-pill--violet">Pro</span> badge — needs the Pro plan or higher.
- An <span class="mp-pill mp-pill--blue">Enterprise</span> badge — needs the
  Business plan or higher (Lifetime counts as Business).

These badges are **enforced**: if your plan is below the badge, **Use Template** won't
install it and you'll see a message saying which plan it needs. Templates with no tier
badge are available to everyone. To see what your plan includes, check **Billing** in
your account settings.

## Good starting points

These are the kinds of automations templates handle well:

- **Tame newsletters** — label and archive promotional mail so your inbox stays for
  real conversations.
- **Surface what's urgent** — when AI marks an email
  <span class="mp-pill mp-pill--red">urgent</span>, star it and keep it in view.
- **Filter cold outreach** — when an email is
  <span class="mp-pill mp-pill--amber">cold_email</span> from a
  <span class="mp-pill mp-pill--gray">cold</span> sender, label and skip the inbox.
- **Route receipts** — label financial and transactional mail and forward copies where
  they need to go.
- **Follow up automatically** — start a **[nudge flow](../tracking/nudges-and-reminders.md)**
  that follows up after a few quiet days and stops if they reply.

:::tip Make it yours
Templates are a starting line, not a finish line. The real value comes from tuning a
template to *your* senders and labels. See **[Best practices](./best-practices.md)**.
:::
