# Docs screenshots

Every image under `static/img/screens/` is generated by these scripts from the
real MailPrism app, running locally against a **fake** Supabase filled with
**made-up demo data** (persona: Jordan Avery at Northwind Studio; every person and
company is fictional). No real user data is involved, and nothing talks to
production.

## What's here

| Path | What it does |
|------|--------------|
| `fake-supabase.mjs` | A tiny stand-in for Supabase Auth + PostgREST on port 54321 |
| `fixtures.mjs`, `fixtures-extra/` | The demo rows it serves (tables, RPCs, counts) |
| `api-mocks.mjs`, `api-mocks/` | Responses for app `/api/*` calls that need Gmail or Google |
| `persona.mjs`, `scripts/*-data.mjs` | Shared demo ids, people and emails |
| `jobs/docs.mjs` | The shot list: page, route, any clicks, and the output name |
| `shoot-batch.mjs` | Opens each route in Chromium at 1440×900 @2x and saves a PNG |
| `emails/render-emails.tsx` | Renders every MailPrism email from the app's own template code |
| `emails/shoot-emails.mjs` | Frames each rendered email in a neutral mail window and saves a PNG |
| `to-webp.py` | Converts PNGs to WebP for `static/img/screens/` |
| `make-env.mjs` | Writes the `.env.local` that points the app at the fake Supabase |

## Re-shoot

Assumes the MailPrism repo is checked out next to this one (`../MailPrism`), or set
`MAILPRISM_DIR`. Needs Node 22 and Python 3 with Pillow.

```bash
cd scripts/screenshots

# 1. Point a local MailPrism at the fake backend (back up any real .env.local first)
node make-env.mjs > ../../../MailPrism/.env.local
(cd ../../../MailPrism && npm ci && npx next dev -p 3000) &
node fake-supabase.mjs &

# 2. App screens (one name, or none for all)
node jobs/docs.mjs > jobs/docs.json
OUT=shots-png node shoot-batch.mjs jobs/docs.json            # all
OUT=shots-png node shoot-batch.mjs jobs/docs.json inbox/compose   # just one

# 3. Emails
(cd ../../../MailPrism && UNSUBSCRIBE_SIGNING_SECRET=demo NEXT_PUBLIC_APP_URL=https://app.mailprism.ai \
  npx tsx --tsconfig tsconfig.json ../mailprism-docs/scripts/screenshots/emails/render-emails.tsx /tmp/emails)
node emails/shoot-emails.mjs /tmp/emails shots-png/emails

# 4. Convert and copy into the site
python3 to-webp.py shots-png ../../static/img/screens
```

Set `CHROME_PATH` if Playwright's own Chromium isn't installed. `LOGAPI=1` prints
any `/api` call that failed (add a mock for it); `LOGC=1` prints console errors.

## Rules for new shots

- Demo data only. No real names, companies, brands as senders, or real IP addresses
  (use `203.0.113.x` / `198.51.100.x`).
- No prices: the Billing shot is cut above the plan comparison.
- Add the shot to `jobs/docs.mjs`, then reference it from a page with
  `<Screenshot src="/img/screens/<name>.webp" alt="…" />` (`srcDark` for a dark
  variant). `alt` describes what the screenshot shows.
